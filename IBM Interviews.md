#### Question 4
A palindrome reads the same from left or right. 
You receive a palindrome that must be modified, if possible. 

You have to change at most one character to another character in the range ASCII $[a, z]$ 
so that the string follows three conditions
- the new string is lower alphabetically than the initial string
- the new string is the lowest value string alphabetically that can be created from the original palindrome after making only one change
- the new string is not a palindrome 

Return the new string, or, if not possible to create it, return "IMPOSSIBLE". 

**Example:**
The palindrome string is "aaabbaaa"
- the possible strings that are lower alphabetically than "aaabbaaa" after one change are "aaa**a**baaa" and "aaab**a**aaa"
- "aaa**a**baaa" is not a palindrome and it is the lowest string that can be created from the input string
